# MP Creation – Link in Bio (Hub)

Cette page est la **Link in Bio** de Maxime, construite à l'aide du projet [Open Bento](https://yoanbernabeu.github.io/openbento/) pour créer un layout moderne et responsive.

---

## 🌐 URL

[https://hub.mp-creation.be](https://hub.mp-creation.be)

---

## 🚀 Description

La page permet de regrouper rapidement tous mes liens importants :

- Réseaux sociaux (YouTube, Instagram, etc.)  
- Portfolio et projets récents  
- Contacts professionnels  

Le layout est basé sur **Open Bento**, offrant une grille flexible et esthétique pour organiser les boutons et icônes.

---

## 🛠 Technologies utilisées
 
- **Open Bento** pour le layout et les blocs interactifs  
- **Vercel** pour le déploiement

---

## ⚡ Fonctionnalités

- Layout responsive en grille grâce à Open Bento  
- Boutons sociaux animés au hover  
- Bouton “Link in Bio” stylisé pour rediriger vers le portfolio principal  
- Animations d'apparition des éléments
